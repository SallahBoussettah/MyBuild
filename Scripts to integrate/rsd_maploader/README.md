### ✅ Main Features

  - Possibility to spawn XML maps
  - Possibility to delete objects from World
  - Fully optimized

### 🔧 Download & Installation

1. Download the latest version from your [keymaster].
2. Unzip the package [rsd_maploader.zip].
3. Ensure the resource in your resources files like this > "ensure rsd_maploader".
4. Configure what you want in the config file.
5. Start the resource and it's ready !

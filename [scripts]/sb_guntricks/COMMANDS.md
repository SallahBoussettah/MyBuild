# SB Gun Tricks - Commands Reference

## Available Commands

| Command | Description |
|---------|-------------|
| `/guntrick` | Toggles the gun tricks menu on/off |
| `/gt` | Short alias for `/guntrick` |

## Gun Tricks Controls

Once you've enabled gun tricks mode with one of the commands above, use these controls:

| Control | Action |
|---------|--------|
| R | Perform the selected trick |
| X | Exit trick mode |
| Left Arrow | Previous trick |
| Right Arrow | Next trick |

## Requirements

- You must be holding a revolver or pistol to perform tricks
- Your character must not be in the middle of another animation
- You must not be dead or incapacitated

## Examples

```
/gt
```
Toggles gun tricks mode on or off.

```
/guntrick
```
Same as above, just the full command version.

## Troubleshooting

If the commands aren't working:

1. Make sure you're typing them correctly in chat
2. Check the server console for any error messages
3. Ensure the script is properly installed and started
4. Try restarting the script or the server
